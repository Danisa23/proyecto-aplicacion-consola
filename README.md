# Aplicación de Consola - JavaScript

## Descripción

Este proyecto corresponde al **Módulo 3: Fundamentos de Programación en JavaScript**.

La aplicación consiste en un programa interactivo que permite al usuario ingresar datos y realizar operaciones matemáticas básicas. Además, incorpora diferentes conceptos fundamentales de JavaScript, como variables, funciones, estructuras condicionales, ciclos, arreglos, objetos y métodos para recorrer y manipular datos.

## Objetivo

El objetivo del proyecto es aplicar los conocimientos fundamentales de programación en JavaScript mediante el desarrollo de una aplicación interactiva ejecutada desde el navegador.

## Funcionalidades

La aplicación permite:

* Ingresar el nombre del usuario.
* Mostrar un mensaje de bienvenida personalizado.
* Ingresar dos números.
* Validar que los datos ingresados sean números válidos.
* Realizar operaciones matemáticas básicas:

  * Suma.
  * Resta.
  * Multiplicación.
  * División.
* Seleccionar operaciones mediante un menú.
* Utilizar estructuras condicionales `if`, `else` y `switch`.
* Utilizar ciclos `for` y `while`.
* Crear y utilizar funciones.
* Trabajar con arreglos.
* Trabajar con objetos.
* Recorrer arreglos de objetos.
* Utilizar el método `forEach()`.
* Utilizar el método `map()`.
* Utilizar el método `filter()` para filtrar estudiantes.

## Tecnologías utilizadas

* **HTML5:** estructura de la aplicación.
* **JavaScript:** programación y funcionamiento de la aplicación.
* **Visual Studio Code:** editor utilizado para desarrollar el proyecto.
* **Navegador web:** ejecución y prueba de la aplicación.

## Ejecución del proyecto

Para ejecutar la aplicación:

1. Abrir la carpeta del proyecto en **Visual Studio Code**.
2. Verificar que los archivos `index.html` y `app.js` se encuentren dentro de la carpeta.
3. Abrir el archivo `index.html` en un navegador web.
4. Seguir las instrucciones que aparecen en pantalla.
5. Ingresar los datos solicitados y seleccionar las operaciones disponibles.

## Validación de datos

La aplicación incorpora validaciones para evitar que el usuario ingrese datos incorrectos. En caso de ingresar valores que no sean números válidos, el programa muestra un mensaje de error y solicita información válida.
